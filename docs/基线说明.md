# 基线来源与组件边界

Microsoft GraphRAG 提供通用索引与查询引擎，源码位于 `packages/`。上游来源为 [microsoft/graphrag](https://github.com/microsoft/graphrag)，导入快照为 `f40e9a26ce62ba0b3fef8837d24aafdcc6e6c704`，组件版本为 `3.1.2`。源码沿用仓库根目录的 MIT 许可证和原有版权声明。

## 组件职责

| 组件 | 职责 |
|---|---|
| `packages/graphrag/` | 索引流程、实体关系抽取、社区摘要、Basic/Local/Global/DRIFT 查询 |
| `packages/graphrag-chunking/`、`graphrag-input/` | 文本读取、切分与输入转换 |
| `packages/graphrag-common/`、`graphrag-llm/` | 通用配置、模型接口与调用控制 |
| `packages/graphrag-storage/`、`graphrag-cache/`、`graphrag-vectors/` | 表存储、缓存与向量存储 |
| `graphrag6-retrieval/` | 项目自定义检索、路径评分与证据记录 |
| `graphrag-workbench/` | 索引管理、多方法对照、引用与子图展示 |
| `scripts/` | 数据预处理、embedding 服务和实验评测 |

上游引擎的通用能力不作为项目自研算法成果。自定义方法的实现、参数和比较范围见[方法与实现](GraphRAG方法调研与系统实现细节.md)。模型兼容与索引质量限制见[实验结果](实验结果与Enron案例.md)。

## 模型与对照条件

项目实验使用 DeepSeek API 完成抽取与生成，本地 `Qwen/Qwen3-Embedding-0.6B` 提供向量。Vector 与 Graph 的比较需复用原文、切分、embedding、生成模型与回答协议，并记录上下文预算和检索参数。

索引及查询会调用模型服务，成本取决于文本量、社区结构和并发配置。索引版本、模型 revision、向量维度与归一化方式必须与查询端一致。配置和命令见[配置与运行](配置与运行.md)。
