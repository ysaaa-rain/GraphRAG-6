# 开发与维护

## 代码与配置

`packages/` 保存上游引擎组件，`graphrag6-retrieval/` 保存项目检索实现，`graphrag-workbench/` 保存界面与编排。修改目录、配置字段或命令时，同步更新运行说明和调用方；修改检索与评测口径时，同步说明结果的适用范围。

密钥保存在本地环境变量或 `.env`，不提交仓库。依赖版本和工作区关系通过 `pyproject.toml` 与对应的 `uv.lock` 管理；引擎组件版本与跨包约束需保持一致。

## 验证范围

- 引擎关键测试和命令见[测试说明](../tests/README.md)。
- 算法测试位于 `graphrag6-retrieval/tests/`。
- 界面与编排测试位于 `graphrag-workbench/tests/`。

功能修改运行相关测试；只整理文档或文件位置时，核对路径、配置语法、引用关系和 Git 差异。未执行的测试不能写作已通过。

## 结果与证据

实验保留代码版本、模型版本、配置、输入范围、原始输出和指标口径。不同语料分母、模型或检索预算产生的结果不能直接混合比较。失败、不可计算指标和证据缺失均需保留说明。

提交说明记录修改目的、影响和实际验证结果。实验结论集中在方法、实验和数据文档中，代码演进由 Git 历史追踪。
