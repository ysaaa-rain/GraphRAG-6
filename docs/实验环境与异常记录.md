# 实验环境与异常记录

本文件保留影响结果解释和复现的环境与异常事实。系统结果见[实验与 Enron 案例](实验结果与Enron案例.md)，代码演进见 [Git 提交历史](https://github.com/ysaaa-rain/GraphRAG-6/commits/main/)。

## 基线环境

2026-09-06 的检查记录使用 Python 3.12.14。GraphRAG CLI 帮助与代码编译通过；当时的 `pytest tests/unit --ignore=tests/unit/chunking/test_chunker.py -q` 得到 310 passed。该数字对应历史代码与测试范围，不代表当前测试集合已经执行通过。

当时完整单元测试受到 NLTK `wordnet` 资源下载限制，不能将完整测试写为通过。文本切分与 NLP 抽取依赖所需 NLTK 资源；执行相关用例前需准备其使用的 NLTK 数据资源。

## Medical 评测异常

- MPS 处理长文本语义指标时，本地 Qwen 服务发生原生退出（退出码 139）并返回 502。该批次未完成记录不作为有效指标；后续从成功 checkpoint 恢复，改用 CPU、并发 1。
- CPU 评测保持相同 Qwen 模型 revision、1024 维与 `normalize=false`，没有通过更换 embedding 模型处理故障。
- retrieval 指标中的非有限值曾导致 JSON 写入中断；评测脚本将其记录为 `null`，汇总均值跳过无法计算的单项。
- Medical 最终 generation 与 retrieval 均完成 2,062 道；Complex Reasoning 和 Fact Retrieval 各有 168 道题的 Context Relevancy 与 Evidence Recall 为 null。指标解释见[全量评测说明](GraphRAG-Bench全量评测说明.md)。

## Enron 索引限制

California Power Crisis 索引分母为 66 封邮件。一个社区报告因控制字符未生成，最终保留 35 个 community reports。图谱规模与预处理总量不能替代答案或证据质量评价。
